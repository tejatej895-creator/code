The primary difference between Control Flow and Data Flow in SSIS is their scope of operation:
 Control Flow manages the overall workflow and orchestration of tasks,
 while Data Flow handles the actual movement and transformation of data at the row level.

control flow tasks include overall database level tasks like backup,sql task,FTP,script,web service.history cleanup, maintenance etc
 data flow is the place where exact data processing happens tasks like sorting,aggregations,merging, joins happens
 and sources involve flat files, sql db , excel files etc
